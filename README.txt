ME'MAR BY ANS — Architecture Studio Website
Built with HTML and CSS only.

HOW TO RUN:
1. Extract this folder.
2. Open Visual Studio Code.
3. Select File > Open Folder and choose memar-by-ans.
4. Open index.html.
5. Double-click index.html in File Explorer to view it, or use the Live Server extension in VS Code.

PAGES:
index.html, about.html, projects.html, project-residence.html, residential.html,
commercial.html, interior-design.html, services.html, process.html, gallery.html,
contact.html, social.html

STYLE:
All shared styling is in style.css. Images load from Unsplash URLs and require internet access.
Before publishing, replace the sample email hello@memarbyans.example in contact.html with your actual email.
This is a fresh starter implementation inspired by the screenshot, not the original lost source code.
